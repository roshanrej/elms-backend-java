SPRING SECURITY
To truly master Spring Security rather than just copying configuration files, you should focus your study extensively on these core conceptual pillars:

**1. The Security Filter Chain and `HttpSecurity`**
You must deeply understand that Spring Security operates entirely as a sequence of filters that intercept incoming HTTP requests before they reach your controllers.
*   **What to learn:** Study how to use the `HttpSecurity` object (often structured using the Builder pattern) to define the rules of your filter chain. Focus extensively on how to disable default protections like CSRF, how to set your session creation policy to stateless, and how to explicitly tell Spring which specific URL endpoints require authentication versus which are freely permitted.

**2. The Core Authentication Flow (The "Big Three" Interfaces)**
Instead of memorizing the code, understand the step-by-step delegation of how Spring verifies a user. Study how these three interfaces interact:
*   **`AuthenticationManager`:** Learn how this interface acts as the entry point that accepts a user's unauthenticated credentials.
*   **`AuthenticationProvider`:** Learn how the manager delegates the actual work to a provider. Study the `DaoAuthenticationProvider` specifically, as this is the builtin class used to connect your security flow to a database.
*   **`UserDetailsService` & `UserDetails`:** Extensively study how to implement these interfaces. The provider relies on your custom `UserDetailsService` to fetch a record from your database repository, which must be returned as a `UserDetails` object containing the user's core principles, password, and granted authorities.

**3. The JWT Lifecycle and Stateless Filters**
You need to understand the architectural shift from traditional stateful session IDs (where the server remembers the user) to stateless JSON Web Tokens (where the client proves who they are with every request).
*   **What to learn:** Extensively study the anatomy of a JWT (the payload, claims, and signature). You need to know how to generate a token using a secure cryptographic key (like HMAC SHA-256). Crucially, study how to create a custom filter class that extends **`OncePerRequestFilter`**. You must understand how this filter intercepts every request, extracts the token from the `Authorization` header (by stripping the "Bearer " prefix), and validates the claims before manually authenticating the user in the `SecurityContextHolder`.

**4. Cryptography and Password Encoding**
Never store or verify passwords in plain text.
*   **What to learn:** Study the concept of one-way hashing, which acts as a mathematical "fingerprint" for a password. Extensively learn how to implement the **`BCryptPasswordEncoder`** class. You should understand how to use it to encode a password during user registration, and how to inject it into your `AuthenticationProvider` so Spring automatically hashes incoming login attempts to securely compare them against your database records.
